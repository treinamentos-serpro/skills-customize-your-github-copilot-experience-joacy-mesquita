# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa um jogo da Forca em que os jogadores tentam adivinhar uma palavra oculta antes de esgotar as tentativas. A atividade pratica manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Implementar a palavra oculta e os palpites

#### Descrição
Crie a parte do jogo que seleciona uma palavra e permite ao jogador tentar descobri-la letra por letra, mostrando o progresso após cada palpite.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras do jogador.
- Mostrar as letras descobertas e os espaços ainda ocultos no formato `_ _ _`.

### 🛠️ Controlar as tentativas e o fim da partida

#### Descrição
Adicione o controle das tentativas incorretas e encerre a partida quando o jogador descobrir a palavra ou não tiver mais tentativas.

#### Requisitos
O programa concluído deve:

- Rastrear e exibir quantas tentativas incorretas ainda restam.
- Encerrar a partida quando a palavra for adivinhada ou as tentativas se esgotarem.
- Exibir uma mensagem de vitória ou de derrota ao final da partida.
